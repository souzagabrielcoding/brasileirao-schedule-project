# Brasileirão Schedule Project

## Objetivo

Desenvolver uma aplicação em Python para extrair dados do Campeonato Brasileiro e estimar a distância percorrida por cada clube ao longo da temporada, considerando partidas realizadas e previstas.

## Escopo inicial

- Obter dados da competição e do calendário de partidas.
- Validar e padronizar os dados coletados.
- Identificar as cidades e os locais das partidas.
- Calcular as distâncias associadas aos deslocamentos dos clubes.
- Projetar a distância total ao final da temporada.
- Gerar resultados organizados e reproduzíveis.

## Tecnologias

- Python 3.15.1
- uv para gerenciamento do ambiente e das dependências
- Git para controle de versão
- pytest para testes automatizados
- Ruff para qualidade e formatação do código

## Ambiente de desenvolvimento

A versão do Python está definida em `.python-version`. As dependências são declaradas em `pyproject.toml` e suas versões resolvidas são registradas em `uv.lock`.
